# Nano Gallery

> A modern responsive image gallery website with a clean UI and smooth browsing experience. 

---
 
# 🚀 Overview  

Nano Gallery is a modern AI prompt gallery website designed for showcasing and generating AI images using Gemini AI prompts. The platform allows users to explore creative prompt ideas, view sample AI-generated artworks, and use prompts to generate their own visuals.

The project focuses on a clean gallery-style UI, responsive layouts, smooth browsing experience, and organized prompt collections for AI image inspiration.

Users can browse sample AI-generated images, discover creative prompt styles, and experiment with different visual concepts using Gemini AI.

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/bobby720/Nano-gallery.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd Nano-gallery
```

## 3️⃣ Open the Project

Open the project folder in VS Code or any code editor
---

# ▶️ Run the Project

Since this is a frontend static project, simply open:

```bash
index.html
```

Or use the VS Code Live Server extension.
